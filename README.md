# Marei Launcher

A Windows 11-style home screen for Android, in the colors of your PC
(#609DBF taskbar, #C9DFEA panes, #245E82 labels) with one-color line icons.

## Get the APK — easiest way (no Android Studio)
1. Create a free account at github.com and make a new repository.
2. Upload everything in this folder (drag and drop, keep the folders).
3. Open the **Actions** tab, pick **Build APK**, and click **Run workflow**.
4. After ~5 minutes, open the finished run and download **MareiLauncher-apk**.
5. Unzip it, send `app-debug.apk` to your phone, and tap it to install
   (allow "Install unknown apps" when asked).

## Or with Android Studio
Open this folder, wait for sync, then Build > Build APK(s).

## Make it your home screen
Press the Home button and choose **Marei Launcher** > **Always**,
or go to Settings > Apps > Choose default apps > Home app.
To go back: pick **One UI Home** in the same place.

## Using it
- Tap an app to open it. Long-press for: Pin to Start, Add to desktop,
  Pin to taskbar (up to 4), App info, Uninstall.
- Start button (dot grid) opens Start. "All apps" shows everything.
- Sliders icon in Start: switch Line icons / Original colors.
